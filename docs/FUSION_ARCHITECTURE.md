# Saga Fusion Architecture

## Overview
Middleware layer for Strix Agent Orchestration.

## Modules
- **Context Manager**: Mythos context collapse.
- **Security Policy**: CAI security rules.
- **Tool Guard**: Action interception.
- **Audit Logger**: Decision tracking.
- **Strix Adapter**: Integration layer.

## Integration
- Inherits from `BaseAgent`.
- Uses composition for Saga modules.
- No invasive core changes.
